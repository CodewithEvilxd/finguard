# FinGuard AI Skill Pack

This folder is the single source of truth for the coding agent and the team building FinGuard AI.

## Start here
1. `SKILL.md`
2. `AGENT_INSTRUCTIONS.md`
3. `tracking/TRACKING.md`
4. Read the relevant specifications before implementing the task.

## Main areas
- `architecture/` system and API contracts
- `frontend/` UI/product experience
- `backend/` domain/API rules
- `ml-backend/` model and scoring rules
- `ai/` RAG and investigation assistant
- `data/` dataset and data quality rules
- `database/` schema rules
- `security/` application and AI security
- `devops/` environments, CI/CD, observability
- `qa/` verification strategy
- `product/` acceptance criteria
- `tracking/` progress, issues, roadmap and definition of done
- `demo/` end-to-end demo runbook
- `performance/` performance expectations and measurement rules
