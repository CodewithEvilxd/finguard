# FinGuard AI Roadmap

## Milestone 1 — Product skeleton
Landing page, auth, dashboard shell, service health, database connectivity.

## Milestone 2 — Detection vertical slice
Transaction ingestion -> features -> ML/rules -> score -> alert -> dashboard.

## Milestone 3 — Explainability vertical slice
Alert -> SHAP/rule explanation -> investigation context.

## Milestone 4 — Investigation vertical slice
Alert -> related activity -> RAG -> AI assistant -> human decision -> audit.

## Milestone 5 — Production hardening
Security, tests, observability, performance, accessibility, environment separation.

## Milestone 6 — Competitive polish
Advanced analytics, graph relationships, model monitoring, refined demo narrative.
